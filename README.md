# SN1/SN2 Predictor Engine

A mechanistic reaction predictor for SN1 and SN2 nucleophilic substitution 
reactions, built in Python using RDKit and Tkinter. Developed independently 
and published as an open-source cheminformatics tool.

## What It Does

Given a substrate molecule, this tool predicts whether an SN1 or SN2 reaction 
mechanism is favoured based on key structural and chemical factors including:

- Substrate class (primary, secondary, tertiary)
- Nucleophile strength
- Solvent polarity
- Leaving group ability
- Steric hindrance

The prediction engine encodes established organic chemistry principles into a 
rule-based decision framework, making it a practical educational and analytical 
tool for students and researchers exploring nucleophilic substitution chemistry.

## Motivation

SN1 and SN2 mechanisms are foundational to organic and materials chemistry — 
governing how molecules react, transform, and form new compounds. This project 
was built out of curiosity: to understand whether the decision rules chemists 
apply intuitively could be formalised computationally. The result is a working 
predictor that bridges chemistry knowledge and software engineering.

## Built With

- **Python** — core programming language
- **RDKit** — open-source cheminformatics library for molecular structure 
  analysis
- **Tkinter** — GUI framework for the interactive interface
- **Jupyter Notebook** — development and documentation environment
